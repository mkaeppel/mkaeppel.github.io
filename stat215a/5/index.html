Final Project: fMRI Language Encoding Models

Stat 215A - UC Berkeley | Fall 2025

Project Overview

This project investigates how the human brain represents semantic and contextual information during natural speech perception. Using fMRI data collected while subjects listened to narrative stories from The Moth Radio Hour, we developed computational models to predict brain activity based on linguistic features.

We systematically compared four word embedding approaches to determine which best captures the neural processing of language:

  • Word2Vec - Static embeddings based on local context windows
  • GloVe - Global co-occurrence statistics from large corpora
  • Pretrained BERT - Contextualized transformer embeddings
  • Fine-tuned BERT - BERT adapted to the story corpus using LoRA

Using voxel-wise ridge regression encoding models, we found that the fine-tuned BERT embeddings consistently outperformed all other approaches across multiple evaluation metrics. This suggests that contextualized semantic representations best align with how the human cortex processes narrative language.

The analysis includes extensive data cleaning, exploratory visualization, model validation through cross-validation, interpretability analysis using SHAP and LIME, and stability checks following the PCS (Predictability, Computability, Stability) framework.
