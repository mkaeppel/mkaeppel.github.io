Lab 4: Arctic Cloud Detection with Deep Learning

Stat 215A - UC Berkeley | Fall 2025

Project Overview

This project addresses the challenging problem of distinguishing clouds from Arctic surfaces in satellite imagery. Due to similarities in scattering properties between ice, snow, and cloud particles, automated cloud detection in polar regions remains a significant technical challenge for climate monitoring.

Using data from NASA's Multi-angle Imaging SpectroRadiometer (MISR) instrument, which captures imagery from nine different viewing angles, we developed machine learning models to classify individual pixels as either cloud or clear surface. The dataset consists of 160 Arctic images, with only three containing expert-provided labels for training and validation.

Methodology

Our analysis pipeline consisted of several key components:

  • Feature Engineering: In addition to the expert-designed physical features (NDAI, SD, CORR), we engineered two new spatially-aware features—Gradient Magnitude and Edge Density—which capture local intensity transitions and texture information that proved highly discriminative for cloud detection.
  • Transfer Learning with Autoencoders: We trained a fully convolutional autoencoder on unlabeled images to extract 20 latent features, leveraging the large corpus of unlabeled data to learn meaningful representations without requiring ground truth labels.
  • Spatial Cross-Validation: To account for strong spatial correlations between neighboring pixels, we implemented a custom 9-fold cross-validation scheme that splits images into spatial blocks with padding, preventing data leakage and providing robust performance estimates.
  • Ensemble Modeling: We trained and compared three classification models—Random Forests, Neural Networks, and Support Vector Machines—evaluating them on accuracy, AUC, sensitivity, and specificity.

Key Results: The Random Forest model achieved the best overall performance with 95% accuracy and 0.98 AUC. Our engineered features (Gradient Magnitude and Edge Density) ranked among the top predictors across multiple feature importance metrics, demonstrating the value of domain-informed feature engineering alongside data-driven approaches.

The analysis includes extensive diagnostics on model convergence and stability, feature importance analysis using MDI+ and permutation-based methods, post-hoc exploratory analysis of classification errors, and stability checks under various perturbations including different train/validation splits and patch sizes.

This work demonstrates how careful feature engineering, transfer learning from unlabeled data, and rigorous cross-validation can be combined to build robust classifiers for challenging remote sensing tasks with limited labeled training data.
